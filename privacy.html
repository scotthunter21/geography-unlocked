Privacy policy

Last updated 27 October 2026

This policy covers the Geography Unlocked tool, a private application the owner of the Geography Unlocked YouTube channel uses to manage that channel. Only the channel owner signs in to it.

What it accesses

With the channel owner's permission, given through Google sign-in, the tool uses the YouTube Data API and YouTube Analytics API to:

  • upload the owner's own videos to their channel (always as unlisted),
  • read the privacy status and public statistics of the channel's own videos, and
  • read the channel's own analytics reports (views, watch time, audience retention, traffic sources, subscribers gained).

How the data is used and stored

The data is used only to publish the owner's videos and to help the owner understand how their own videos perform. It is stored locally on the owner's own computer. It is not sold, shared with third parties, or used for advertising.

The tool does not collect any information about YouTube viewers beyond the aggregated statistics YouTube Analytics provides to channel owners.

Google API Services

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements. It also uses YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time from Google account permissions. Locally stored data is deleted on request.
